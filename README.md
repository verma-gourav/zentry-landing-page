# 🌌 Zentry Landing Page Clone

A frontend clone of the [Zentry.com](https://zentry.com) landing page built for learning purposes.  
This project focuses on practicing modern UI/UX design, animations, and responsive layouts using **React + TailwindCSS**.

---

## 🛠️ Tech Stack

- React 19
- Tailwind CSS (v4)
- GSAP (for animations)
